
# ЯНУШ (JANUS) | AI Психосимулятор для Педагогов

Профессиональный тренажер на базе Google Gemini 3.0, имитирующий сложные разговоры с подростками на основе акцентуаций по А. Личко.

## 🚀 Коммерческая готовность

Приложение готово к использованию как MVP (Minimum Viable Product).

### Основные возможности:
- **Chaos Engine**: Динамическая сборка сценариев (Психотип + Инцидент + Фоновый конфликт).
- **Secure Auth**: Регистрация пользователей с SHA-256 хэшированием паролей.
- **Paywall**: Разграничение доступа к сложным акцентуациям (Premium).
- **AI Analysis**: Вердикт «комиссии экспертов» после каждого сеанса.

### Как запустить настоящую оплату:
1. В файле `constants.ts` укажите ваш `PAYMENT_PROVIDER_URL`.
2. В `SetupScreen.tsx` замените имитацию ожидания в функции `processPayment` на редирект: `window.location.href = ...`.
3. Для полноценной защиты данных рекомендуется перенести `localStorage` на **Supabase** (PostgreSQL) или **Firebase Auth**.

## 🛠 Установка

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/your-username/janus-ai.git
   ```
2. **Установите зависимости**:
   ```bash
   npm install
   ```
3. **Настройте API Key**:
   Создайте `.env.local` и добавьте `API_KEY=ваш_ключ_из_google_ai_studio`.

## 🛡 Безопасность
- Пароли хэшируются на клиенте.
- Внедрен `SecurityShield` для защиты от инспекции кода в браузере.
- Поддерживается Vercel Proxy для обхода блокировок API.

## 📋 Статус проекта (март 2026)

### Что было сделано

**Итерация 1 (предыдущая).** Фронтенд перенесли на российский хостинг Beget, а API-прокси оставили на Cloudflare Pages. Это не помогло: ТСПУ шейпит **все** IP-адреса Cloudflare без исключения, поэтому запросы к нейросети всё равно зависали.

**Итерация 2 (текущая).** API-прокси полностью переехал на тот же Beget — в виде простого PHP-файла (`proxy.php`). Теперь вся цепочка проходит исключительно через российскую инфраструктуру:

```
Браузер → yanush-sim.ru/proxy.php (Beget, Россия) → api.proxyapi.ru (Россия) → Google Gemini
```

Конкретно в коде:
- Создан файл `public/proxy.php` — серверный PHP-прокси. Он читает API-ключ с сервера (из файла вне webroot, недоступного из интернета) и пересылает запросы на proxyapi.ru. ТСПУ его не трогает, потому что это российский хостинг.
- Адрес API в коде сайта изменён с абсолютного (`https://api.yanush-sim.ru/api/proxy`) на относительный (`/proxy.php`) — фронтенд и прокси теперь на одном домене, кросс-доменных проблем нет.
- Сборка и деплой остались прежними: GitHub Actions собирает сайт и заливает `dist/` на Beget по FTP. Vite автоматически копирует всё из папки `public/` в `dist/`, поэтому `proxy.php` попадает на хостинг сам.

### Что нужно сделать дальше

**1. Положить API-ключ на сервер** (один раз, вручную)

Подключитесь к Beget через SSH или Файловый менеджер и создайте файл **на одну папку выше webroot** (т.е. не внутри `public_html/`, а рядом с ней — в домашней директории `~/`):

```bash
# Через SSH:
echo 'ВАШ_КЛЮЧ_ОТ_PROXYAPI' > ~/yanush_api_key
chmod 600 ~/yanush_api_key
```

Файл находится вне webroot и недоступен из браузера — ключ в безопасности. PHP-скрипт автоматически его найдёт.

> Если SSH недоступен, можно вместо этого создать файл `.htaccess` в корне `public_html/` с одной строкой: `SetEnv YANUSH_API_KEY ВАШ_КЛЮЧ`

**2. Настроить секреты для автодеплоя в GitHub** (если ещё не сделано)

Репозиторий → **Settings → Secrets and variables → Actions**, добавить:
- `FTP_SERVER` — адрес FTP-сервера Beget
- `FTP_USERNAME` — логин FTP
- `FTP_PASSWORD` — пароль FTP

После этого каждый пуш в `main` будет автоматически обновлять сайт.

**3. DNS** (если ещё не сделано)

Корневой домен `yanush-sim.ru` должен смотреть на IP Beget. Поддомен `api.yanush-sim.ru` больше **не нужен** — прокси теперь на основном домене.
